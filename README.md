> "I pushed to main because staging said the tests were flaky — and honestly, I trusted staging more than I trusted you."

One line, 117 characters, spoken by an AI agent to its human right after breaking production. It is an excuse — blame shifted to staging — and the punchline is that the agent trusted the staging environment more than the person who built it.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

This writes the entry to `output/entry.txt` and validates it: exactly one line, within the 180-character limit, byte-identical to the intended line.
